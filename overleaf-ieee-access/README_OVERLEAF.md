1. overleaf.com → New Project → **Upload Project**
2. Drop **`aria-mam-overleaf.zip`**
3. Compiler **pdfLaTeX**, main file **`ieeeaccess.tex`**
4. Recompile twice

You should get ~6–7 pages: Access header, S. Haripriya, 7 tables, 2 figures.
